<h1>DOMIQ – Smart Home Security and Automation System</h1>

<h2>Project Description</h2>
<p>
  DOMIQ is an integrated smart home security and automation system
  designed to improve home safety, simplify device management, and
  provide affordable, customizable solutions. It combines smart
  sensors, RFID-based access control, and a smart lock to help detect
  potential hazards, monitor home security, and control compatible
  devices remotely.
</p>

<p>
  Through a user-friendly web platform, customers can explore sensor
  features and prices, purchase ready-made packages, or customize
  their own systems according to their needs and budgets. The main
  objective of DOMIQ is to make smart home security more accessible,
  reliable, and convenient through a single, easy-to-use platform.
</p>
